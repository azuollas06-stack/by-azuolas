# BY.AZUOLAS

Portfolio of Ąžuolas, an independent designer from Lithuania: websites, Shopify stores and logos.

- `app/page.tsx`: the whole site, one page (intro video → hero → work → logos → video → services → contact).
- `lib/content.ts`: every project, logo and video listed on the page. Add work here.
- `public/darbai/<slug>/`: the concept sites, served as standalone static pages (`/darbai/silas/index.html`).
- `public/video/intro-*.mp4`: the 3.6 s intro, cut from real screenshots of the work (landscape and portrait).

```bash
npm install
npm run dev
```
